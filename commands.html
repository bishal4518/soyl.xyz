Leveling11 commandsXP from messages and voice, level roles, and leaderboards.
/level addxpManage Server

Add (or remove, with a negative number) XP from a member.

  • user
  • amount
/level configManage Server

Configure the leveling system.

  • xp_min (optional) – Minimum XP per eligible message.
  • xp_max (optional) – Maximum XP per eligible message.
  • cooldown (optional) – Seconds between XP-eligible messages per member.
  • voice_xp (optional) – XP granted per minute spent actively in a voice channel.
  • channel (optional) – Channel where level-up announcements are sent.
  • message (optional) – Level-up announcement text. Supports {usermention}, {username}, {level}, {guildname}.

  • confirm (optional) – Set to true to confirm this irreversible action.

Prefix Commands: 18


!help

Opens the help menu with every command category.
Aliases: !h, !commands

Permission: Send message

!afk

Sets your AFK status with an optional reason and adds an [AFK] tag to your nickname.
Alias: !away

Permission: Send message

!prefix

Shows the current prefix of the server. Mentioning the bot also shows it.

Permission: Send message

!prefix $

Changes the server's prefix (1-5 characters, no spaces). Use "reset" to go back to !.

Permission: Manage Server

!kick

Kicks a member from the server.
Usage: !kick @user reason

Permission: Kick Members

!ban

Bans a user by mention or ID, even if they already left the server.
Usage: !ban @user reason

Permission: Ban Members

!unban

Unbans a user by their ID.
Usage: !unban ID reason

Permission: Ban Members

!mute

Times out a member for a set duration (e.g. 10m, 2h, 1d, up to 28 days).
Alias: !timeout
Usage: !mute @user 10m reason

Permission: Timeout Members

!unmute

Removes a member's timeout.
Alias: !untimeout
Usage: !unmute @user reason

Permission: Timeout Members

!purge

Deletes a number of recent messages (1-100) in the current channel.
Alias: !clear
Usage: !purge 20

Permission: Manage Messages

!lock

Locks a channel so regular members cannot send messages. Leave the channel empty to lock the current one.

Permission: Manage Channels

!unlock

Unlocks a locked channel so regular members can send messages again.

Permission: Manage Channels

!hide

Hides a channel from regular members. Leave the channel empty to hide the current one.

Permission: Manage Channels

!unhide

Makes a hidden channel visible to regular members again.

Permission: Manage Channels

!role add

Gives a role to a member. Role names with spaces work.
Usage: !role add @user Role Name

Permission: Manage Roles

!role remove

Removes a role from a member.
Usage: !role remove @user Role Name

Permission: Manage Roles

!strip

Removes every role the bot is able to remove from a member and saves them. Restore them with !unstrip.

Permission: Manage Roles

!strip staff

Removes only the staff roles (roles with moderation permissions) from a member and saves them. Restore them with !unstrip.

Permission: Manage Roles

!unstrip

Gives back all the roles removed by !strip or !strip staff.

Permission: Manage Roles
