Soyl

An all-in-one Discord bot for your community: moderation, tickets, leveling, welcome messages, music, and more, all with slash commands.

Add to Discord Support server Browse commands

Features

Everything runs through slash commands, so setup takes a few minutes.

Moderation

Ban, kick, timeout, purge messages, lock or hide channels, manage roles, and strip or restore a member's roles.

Leveling

Members earn XP from messages and voice time. Set level role rewards, ignore channels, and show rank and leaderboards.

Music

Play songs from YouTube links or searches, or paste a Spotify track link. Queue, loop, shuffle, volume, and an optional DJ role.

Tickets

Post a ticket panel with your own purposes, wording, colors, and closing message.

Welcome and introductions

Greet new members with plain text or an embed, and collect introductions through a form with your own questions.

Autoresponders

Reply automatically to trigger words, in every channel or just one.

Create VC

Members join a trigger channel to get their own temporary voice room, with a control panel.

Server logging

Create log channels for server activity with a single command.

Channel rules

Limit a channel to images, video, audio, or text only.

Community events

Run a profile picture event with voting, a partnership panel, and a counting game with stats.

Nickname channel

A dedicated channel for setting nicknames, with success and error reactions you can customize.

AFK status

Let members set an AFK status with a custom reason.

Leveling11 commandsXP from messages and voice, level roles, and leaderboards.

  • amount
/level configManage Server

How to add Soyl

  1. Click Add to Discord. You need the Manage Server permission in the server you want to add Soyl to.
  2. Choose your server and approve the permissions on the Discord screen.
  3. Run /help menu in any channel to see what Soyl can do.
  4. Set up what you need, for example /welcome setup, /ticket setup, or /log setup. Setup commands need the permission listed on the command.

FAQ

Is Soyl free?

Yes. See the Terms of Service for details.

What data does Soyl store?

Only what its features need, such as server settings and leveling data. Read the full Privacy Policy.

What music sources work?

You can use YouTube links or searches, or paste a Spotify track link. Soyl reads the song title from Spotify and plays the audio from YouTube.

Who can use the admin commands?

Each command shows the permission it needs, such as Administrator, Manage Server, or Ban Members. Discord also lets server owners change who can use each command in Server Settings, under Integrations.
