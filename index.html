Privacy Policy

Overview

Soyl is a Discord bot that provides moderation, tickets, leveling, welcome messages, introductions, autoresponders, voice channel tools, music, AFK status, counting, and server logging. This policy explains what data the bot handles when it is added to a server or when you use its commands.

By using the bot or inviting it to a server, you agree to this policy. Last updated: October 14, 2026

Data we collect

The bot only stores what its features need. Here is what is saved, by feature:

FeatureWhat is stored
Server settingsServer ID, channel IDs, role IDs, message IDs, and the text you configure (welcome messages, embed text, autoresponder triggers and replies, ticket panel text, intro questions).
LevelingYour user ID and server ID, XP, message count, time spent in voice channels, and the time of your last XP-earning message.
AFKYour user ID, server ID, AFK reason, your original nickname, and any notes or reminders other members leave for you while you are AFK.
Profile picture eventUser IDs of participants and the IDs of their submission messages.
Counting gameCurrent count, best count, and the ID of the last user who counted.
TicketsTicket channels are created in your server. The ticket owner's user ID is stored in the channel topic. Ticket conversations stay in Discord.
Create VCIDs of temporary voice rooms and the user ID of each room's owner while the room exists.

The bot also reads messages in channels it can see, because several features depend on message content (counting, autoresponders, nickname and profile picture channels, channel restrictions, leveling, and AFK). Message content is processed to run these features. It is not saved to our database, except for the AFK notes and autoresponder text described above.

Introduction answers are posted by the bot as a message in the channel your server chose. They are stored by Discord, not in our database.

Server logging. If a server administrator turns on the logging feature, the bot sends records of server events (such as moderation actions, member activity, messages, channels, roles, and voice activity) to log channels inside that server. Those logs live in Discord and are controlled by that server's administrators.

We do not collect your email address, password, payment details, or location. Music playback is not recorded and no audio is stored.

How we use it

  • To run the features listed above and remember each server's settings between restarts.
  • To calculate levels, ranks, and leaderboards.
  • To enforce moderation actions that a server's staff choose to take.
  • To fix bugs and keep the bot running.

We do not sell your data, use it for advertising, or use it to build profiles outside the bot's features.

Storage and security

Data is stored in a database on the server that hosts the bot. We limit access to the bot owner and take reasonable steps to protect it. No system is completely secure, so we cannot guarantee absolute security.

Some temporary data, such as the music queue and the list of roles removed by a "strip" command, is kept only in memory and is lost when the bot restarts.

Third parties

  • Discord. The bot runs on Discord and is subject to the Discord Privacy Policy.
  • YouTube. When you use the music commands, your search text or link is sent to YouTube to find the audio.
  • Spotify. If you paste a Spotify link, the link is sent to Spotify's public oEmbed service to read the song title. Audio is not streamed from Spotify.
  • Hosting provider. The bot is hosted by nyctohost, which may process data as part of providing the service.

We do not share your data with any other third parties.

Retention and deletion

We keep data for as long as the bot is in the server or until it is no longer needed for a feature. You can remove data in these ways:

  • Server admins can reset leveling for a member with /level reset or for the whole server with /level resetall.
  • Server admins can disable or clear features such as welcome messages, autoresponders, tickets, and counting using their commands.
  • Your AFK data is deleted when you send a message after going AFK.
  • You or a server admin can ask us to delete stored data by contacting us (see below). Removing the bot from a server does not automatically delete its stored data, so please contact us if you want it erased.

Your choices

You can ask us what data we hold about you, ask us to correct or delete it, or stop using the bot at any time. Depending on where you live, you may have additional rights under local privacy laws. We will respond to reasonable requests as soon as we can.

Children

The bot is not meant for children under 13, or under the minimum age required by Discord in your country. If you believe a child's data has been stored, contact us and we will delete it.

Changes to this policy

We may update this policy when the bot changes. The "last updated" date at the top shows the latest version. Continuing to use the bot after a change means you accept the updated policy.
