Soyl

An all-in-one Discord bot for your community: moderation, tickets, leveling, welcome messages, music, and more, all with slash commands.

Add to Discord Support server

Features

Everything runs through slash commands, so setup takes a few minutes.

Moderation

Ban, kick, timeout, purge messages, lock or hide channels, manage roles, and strip or restore a member's roles.

Leveling

Members earn XP from messages and voice time. Set level role rewards, ignore channels, and show rank and leaderboards.

Music

Play songs from YouTube links or searches, or paste a Spotify track link. Queue, loop, shuffle, volume, and an optional DJ role.

Tickets

Post a ticket panel with your own purposes, wording, colors, and closing message.

Create VC

Members join a trigger channel to get their own temporary voice room, with a control panel.

Server logging

Create log channels for server activity with a single command.

Channel rules

Limit a channel to images, video, audio, or text only.

Community events

Run a profile picture event with voting, a partnership panel, and a counting game with stats.

Leveling11 commandsXP from messages and voice, level roles, and leaderboards.
/level addxpManage Server

Add (or remove, with a negative number) XP from a member.

  • user
  • amount
/level configManage Server

Configure the leveling system.

  • xp_min (optional) – Minimum XP per eligible message.
  • xp_max (optional) – Maximum XP per eligible message.
  • cooldown (optional) – Seconds between XP-eligible messages per member.
  • voice_xp (optional) – XP granted per minute spent actively in a voice channel.
  • channel (optional) – Channel where level-up announcements are sent.
  • message (optional) – Level-up announcement text. Supports {usermention}, {username}, {level}, {guildname}.
/level ignore_channelManage Server

Stop a channel's messages from granting XP.

  • channel
/level resetManage Server

Reset a member's XP and level.

  • user
/level resetallManage Server

Reset the ENTIRE leveling leaderboard for this server.

  • confirm (optional) – Set to true to confirm this irreversible action.
/level role_addManage Server

Grant a role automatically when a member reaches a level.

  • level – The level required.
  • role – The role to grant.
/level role_listEveryone

List all level role rewards.

/level role_removeManage Server

Remove a level role reward.

  • level – The level to remove the reward from.
/level setManage Server

Manually set a member's level.

  • user
  • level
/level toggleManage Server

Enable or disable the leveling system.

/level unignore_channelManage Server

Allow a channel's messages to grant XP again.

  • channel

Moderation14 commandsBan, kick, timeout, purge, lock channels, and manage roles.
/moderation banBan Members

Ban a member from the server.

  • member – The member to ban.
  • reason (optional) – Reason for the ban.
  • delete_days (optional) – Days of the member's messages to delete (0-7).
/moderation hideManage Channels

Hide a channel from regular members.

  • channel (optional) – The channel to hide. Leave empty to hide this channel.
/moderation kickKick Members

Kick a member from the server.

  • member – The member to kick.
  • reason (optional) – Reason for the kick.
/moderation lockManage Channels

Lock a channel so regular members cannot send messages.

  • channel (optional) – The channel to lock. Leave empty to lock this channel.
/moderation muteTimeout Members

Timeout a member.

  • member – The member to timeout.
  • duration – Duration such as 10m, 2h, or 1d.
  • reason (optional) – Reason for the timeout.
/moderation purgeManage Messages

Delete a number of recent messages.

  • amount – Number of messages to delete (1-100).
/moderation role addManage Roles

  • member – The member who will receive the role.

/moderation role removeManage Roles

  • member – The member who will lose the role.
  • role – The role to remove.

  • member – The member whose roles will be removed.
/moderation unbanBan Members

Unban a user.

  • user_id – The ID of the banned user.
  • reason (optional) – Reason for the unban.
/moderation unhideManage Channels

Unhide a channel from regular members.

  • channel (optional) – The channel to unhide. Leave empty to unhide this channel.
/moderation unlockManage Channels

Unlock a channel so regular members can send messages.

  • channel (optional) – The channel to unlock. Leave empty to unlock this channel.
/moderation unmuteTimeout Members

Remove a member's timeout.

  • member – The member to unmute.
  • reason (optional) – Reason for removing the timeout.
/moderation unstripManage Roles

Restore roles previously removed with /moderation strip.

  • member – The member whose saved roles should be restored.

How to add Soyl

  1. Click Add to Discord. You need the Manage Server permission in the server you want to add Soyl to.
  2. Choose your server and approve the permissions on the Discord screen.
  3. Run /help menu in any channel to see what Soyl can do.
  4. Set up what you need, for example /welcome setup, /ticket setup, or /log setup. Setup commands need the permission listed on the command.

FAQ

Is Soyl free?

Yes. See the Terms of Service for details.

What data does Soyl store?

Only what its features need, such as server settings and leveling data. Read the full Privacy Policy.

What music sources work?

You can use YouTube links or searches, or paste a Spotify track link. Soyl reads the song title from Spotify and plays the audio from YouTube.

Who can use the admin commands?

Each command shows the permission it needs, such as Administrator, Manage Server, or Ban Members. Discord also lets server owners change who can use each command in Server Settings, under Integrations.
